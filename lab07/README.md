Лабораторная работа 7. Функции и автоматические проверки

Вариант 2. Числа меньше порога.
Цель: научиться создавать функции, возвращать результат и проверять его через assert.

Файлы:
functions.py — функции для вычислений.
main.py — ввод данных и вывод результатов.
test_functions.py — автоматические проверки.

Запуск из папки lab07 через Python 3:
python main.py
python test_functions.py

В main.py по очереди вводятся целое число, список целых чисел одной строкой,
текст и целый неотрицательный порог. При отрицательном пороге ввод повторяется.

Проверка с намеренной ошибкой:
Во временной копии functions.py условие number < threshold заменено на number <= threshold.
Ожидаемый результат: тест выдаёт AssertionError, потому что число 2 не должно попадать в результат при пороге 2.
Фактический результат: получен AssertionError.
Итоговый functions.py содержит правильное условие <, проверки проходят.

Для защиты:
return возвращает результат функции, print() выводит его на экран.
Параметр получает значение при вызове функции.
Локальная переменная создаётся внутри функции и используется в ней.
assert проверяет условие и выдаёт ошибку, если оно ложно.
Проверка порога в main.py сделана через while, а не через assert.
