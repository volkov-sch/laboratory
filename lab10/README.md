Вариант 2. Сумма отрицательных элементов исходной матрицы.
Проверено на Python 3.12.10. Внешние библиотеки не нужны.

Файлы:
files_lab.py — чтение и проверка таблицы, selected_sum.
main.py — надёжный ввод, обработка ошибок и запись отчёта.

test_files.py — проверки во временной папке.
matrix.txt — исходная таблица в UTF-8.
report.txt — пример полученного отчёта.

Запуск из папки lab10:
python main.py
python test_files.py

Сначала программа показывает первое задание: ввод положительного размера.
После этого читает отдельную таблицу из matrix.txt. Её размеры берутся из заголовка файла.
Файлы находятся относительно папки скрипта, а не текущей рабочей папки.

Формат matrix.txt:
Первая строка содержит два положительных целых числа: высоту и ширину.
Дальше идут ровно указанное число строк и число элементов в каждой строке.
Пустые и лишние строки запрещены. Один перевод строки после последних данных допустим.

Учебный файл:
2 3
1 -2 3
4 0 -6

Ручной расчёт:
Суммы строк: 1 - 2 + 3 = 2; 4 + 0 - 6 = -2.
Суммы столбцов: 1 + 4 = 5; -2 + 0 = -2; 3 - 6 = -3.
Отрицательные элементы: -2 + (-6) = -8.

Ожидаемый и фактический report.txt:
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: -8

Проверка надёжного ввода:
abc → Это не целое число.
0 → Число должно быть больше нуля.
-2 → Число должно быть больше нуля.
3 → Принятый размер: 3.
Ожидаемый и фактический результат совпали.

Проверки чтения:
1 2 и строка 7 -1 → [[7, -1]].
1 1 и строка 0 → [[0]].
Пустой файл → ValueError.
Размеры 0 3 или 1 0 → ValueError с указанием строки 1.
Нечисловой заголовок или три размера → ValueError для строки 1.
Размеры 1 2 и строка 1 → ValueError для строки 2.
Размеры 1 2 и строка 1 x → ValueError для строки 2.
Лишняя строка данных или пустая строка после данных → ValueError.
Недостающая строка → ValueError с номером ожидаемой строки.
Отсутствующий файл → FileNotFoundError в функции и сообщение в основной программе.
Все ожидаемые результаты получены.

Сохранность старого отчёта проверена запуском основной программы в отдельной папке.
До запуска в report.txt записан текст «Старый отчёт не менять».
При нечисловой ячейке, лишней пустой строке, отсутствии matrix.txt и неправильной кодировке
программа показала ошибку, а report.txt остался без изменений.
Исходный matrix.txt тоже не изменился.
