Лабораторная работа 5. Обработка строк

Вариант 2. Слова, которые заканчиваются на я.
Цель: научиться обрабатывать строки с помощью методов, срезов и циклов.

Файлы:
normalize.py
palindrome.py
replace.py
variant.py

Запуск из папки lab05 через Python 3:
python normalize.py
python palindrome.py
python replace.py
python variant.py

Для защиты:
Строка неизменяемая: методы возвращают новую строку.
Слово здесь получается через split(), а подстрока — любая часть строки.
В палиндроме убираются только обычные пробелы и не учитывается регистр.
Пунктуация в палиндроме сохраняется, поэтому А! не является палиндромом.
В варианте знаки .,!?;: удаляются только по краям каждого слова.
