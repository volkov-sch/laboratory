3. Предсказание результата

Перед запуском программы результаты вычислил вручную.

2 + 3 * 4

Мой прогноз: 14

Результат Python: 14

Объяснение:
Сначала выполняется умножение, потом сложение.


(2 + 3) * 4

Мой прогноз: 20

Результат Python: 20

Объяснение:
Сначала выполняется действие в скобках, потом умножение.


17 // 5

Мой прогноз: 3

Результат Python: 3

Объяснение:
Оператор // выполняет целочисленное деление с округлением вниз.


17 % 5

Мой прогноз: 2

Результат Python: 2

Объяснение:
Оператор % показывает остаток от деления.


-7 // 2

Мой прогноз: -4

Результат Python: -4

Объяснение:
-7 / 2 = -3.5. При использовании // результат округляется вниз, поэтому получается -4.

Различий между моими прогнозами и результатами Python не было.
