Лабораторная работа 9. Вложенные списки и таблицы

Автор: Волков Иван.
Вариант 2. Положительные элементы заменяются единицами.
Проверено на Python 3.12.10. Внешние библиотеки не нужны.

Файлы:
table.py — функции обработки таблиц без ввода и вывода.
main.py — ввод размеров, таблицы и вывод результатов.
test_table.py — автоматические проверки.

Запуск из папки lab09:
python main.py
python test_table.py

Порядок ввода:
Количество строк, количество столбцов, затем строки целых чисел через пробел.
После обработки таблицы ввожу положительный размер диагонального узора.
Размеры должны быть больше нуля, длина каждой строки должна совпадать с шириной.
При неверном размере или количестве элементов ввод повторяется.
По условию этой работы числа вводятся правильного типа.

Проверка прямоугольной таблицы:
1 2 3
4 5 6
Ожидаемые суммы строк: [6, 15].
Ожидаемые суммы столбцов: [5, 7, 9].
Фактические суммы: [6, 15] и [5, 7, 9].

Одна ячейка [[7]] → обе суммы [7].
Один столбец [[1], [-1], [0]] → суммы строк [1, -1, 0], столбцов [0].
Пустая таблица [] → суммы и преобразование [].
Ожидаемые и фактические результаты совпали.

Узор размера 1: [[0]].
Узор размера 3:
0 1 1
2 0 1
2 2 0
Фактический узор совпал с ожидаемым.

Проверка варианта 2:
Исходная таблица: [[-2, 0, 3], [4, -5, 6]].
Ожидаемый результат: [[-2, 0, 1], [1, -5, 1]].
Фактический результат: [[-2, 0, 1], [1, -5, 1]].
Исходная таблица не изменилась.
После изменения result[0][0] исходная таблица осталась прежней.
Строки узора тоже независимы: изменение первой не затронуло остальные.

Проверка ввода:
Для размера 0 программа повторила запрос.
При ширине 3 и вводе строки 1 2 программа попросила ровно 3 числа.
После повторного ввода 1 2 3 обработка продолжилась.

Результат запуска тестов: Все проверки таблиц пройдены.
