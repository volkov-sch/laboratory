6. variant.py

Индивидуальный вариант 2.

Заказ: Книжный магазин
Первая позиция: Учебники
Вторая позиция: Сборники задач

Проверка 1

Ввод:
Название заказа: Книжный магазин
Имя заказчика: Иван Иванов
Название первой позиции: Учебники
Количество: 3
Цена: 12.50
Название второй позиции: Сборники задач
Количество: 2
Цена: 20.00
Стоимость доставки: 10.00
Внесённая сумма: 100.00

Расчёт:

Учебники:
3 × 12.50 = 37.50 руб.

Сборники задач:
2 × 20.00 = 40.00 руб.

Стоимость товаров:
37.50 + 40.00 = 77.50 руб.

Итого с доставкой:
77.50 + 10.00 = 87.50 руб.

Количество единиц:
3 + 2 = 5

Сдача:
100.00 - 87.50 = 12.50 руб.

Ожидаемый результат:
Стоимость учебников: 37.50 руб.
Стоимость сборников задач: 40.00 руб.
Стоимость товаров: 77.50 руб.
Всего с доставкой: 87.50 руб.
Количество единиц: 5
Сдача: 12.50 руб.

Фактический результат:
Стоимость учебников: 37.50 руб.
Стоимость сборников задач: 40.00 руб.
Стоимость товаров: 77.50 руб.
Всего с доставкой: 87.50 руб.
Количество единиц: 5
Сдача: 12.50 руб.
