HTTP-упражнение:
Адрес https://api.github.com/users/ плюс логин запрашивает профиль пользователя GitHub.
Это профиль пользователя, а не сведения о репозитории.
GET используется для получения данных. Заголовок User-Agent задаёт имя учебной программы.
timeout=10 ограничивает ожидание сетевой операции, чтобы программа не ждала бесконечно.
HTTPError показывает код ответа сервера. URLError и TimeoutError обрабатывают сетевые проблемы.
ValueError и UnicodeError относятся к данным ответа; OSError — к файловому доступу.
