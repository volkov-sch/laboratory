Лабораторная работа 6. Списки и обработка наборов данных

Вариант 2. Отрицательные числа.
Цель: научиться создавать, обходить и обрабатывать списки.

Файлы:
statistics.py
transform.py
positions.py
variant.py

Запуск из папки lab06 через Python 3:
python statistics.py
python transform.py
python positions.py
python variant.py

Числа вводятся одной строкой через пробел.
Для пустого ввода нужно сразу нажать Enter.

Для защиты:
append() добавляет элемент в конец списка.
Присваивание по индексу заменяет уже существующий элемент.
sorted() создаёт новый отсортированный список, sort() меняет исходный.
В transform.py элементы добавляются в отдельный список, поэтому исходный сохраняется.
Индексы элементов начинаются с нуля.

Вывод: научился обрабатывать списки и сохранять исходные данные.
