Лабораторная работа 3

Цель: изучить условные операторы if, elif, else и логические операторы.

Файлы:
minimum.py
calculator.py
point.py
variant.py

Запуск:
python minimum.py
python calculator.py
python point.py
python variant.py

Проверка minimum.py

Ввод: 2, 10, 3
Ожидаемый ответ: Минимум: 2
Фактический ответ: Минимум: 2

Ожидаемый ответ: Минимум: 5
Фактический ответ: Минимум: 5

Ввод: -4, 0, -2
Ожидаемый ответ: Минимум: -4
Фактический ответ: Минимум: -4
